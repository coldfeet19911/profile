# 치이카와 산업안전보건 강사 홈페이지

## 폴더 구성
- index.html : 홈페이지 전체 코드(HTML/CSS/JavaScript)
- images/profile.png : 전달받은 프로필 이미지

## 실행
index.html 파일을 더블클릭하면 브라우저에서 열립니다.

## 배포 전 반드시 수정할 내용
1. index.html에서 [수정 11]을 찾아 `YOUR_EMAIL@example.com`을 실제 신청 수신 이메일로 변경하세요.
2. FormSubmit에서 첫 신청 테스트 후 해당 이메일로 온 인증 메일을 확인하세요.
3. 강의 과정은 실제 제공 가능한 과정만 남기고 수정하세요.
4. 공단과의 실제 소속 관계가 확인되기 전까지 홈페이지에는 '관련 기관'으로만 표시되어 있습니다.

## 사진 교체
새 사진을 images 폴더에 넣고 index.html의 [수정 05] 구역에서
`src="images/profile.png"`를 새 파일명으로 변경하세요.

## GitHub Pages
GitHub 저장소에 index.html과 images 폴더를 올린 뒤
Settings > Pages > Deploy from a branch > main / (root) > Save를 선택하세요.
